Data Sources

Built on Real CMS Public Data

All data is sourced directly from CMS public datasets. No synthetic data was used. The datasets were downloaded, cleaned in Power Query, and joined in the Power BI data model before any DAX measures were written.

Medicare Part D Prescribers by Provider and Drug

CMS public dataset covering prescriber-level GLP-1 drug spend, claim counts, and beneficiary counts by year (2019-2023).

Medicare Part D Spending by Drug

Aggregated national drug-level spending, average cost per claim, and beneficiary totals used for trend and CAGR calculations.

FDA Drug Approval Records

FDA approval dates for GLP-1 receptor agonists used to build the policy timeline annotation layer on Page 2.

CBO and CMS Projection Estimates

Congressional Budget Office and CMS actuarial projections used as the basis for the Status Quo and BALANCE Model spending forecasts on Page 3.

Key DAX Measures

Core Calculations

Three DAX measures drive the analytical logic of this dashboard. The BALANCE projection measure is the most technically involved because it reads from a What-If Parameter table rather than a hardcoded value, making the discount assumption fully interactive.

5-Year CAGR

CAGR 5yr =
VAR StartYear = CALCULATE([Total Spending], FILTER(ALL(Dates), Dates[Year] = 2019))
VAR EndYear   = CALCULATE([Total Spending], FILTER(ALL(Dates), Dates[Year] = 2023))
RETURN
    DIVIDE(EndYear, StartYear) ^ (1 / 4) - 1

Status Quo Projection (2024–2027)

Projected Spending Status Quo =
VAR BaseYear   = CALCULATE([Total Spending], FILTER(ALL(Dates), Dates[Year] = 2023))
VAR YearsAhead = MAX(Dates[Year]) - 2023
RETURN
    BaseYear * (1 + [CAGR 5yr]) ^ YearsAhead

BALANCE Model Projection (What-If Parameter driven)

Projected Spending BALANCE =
    [Projected Spending Status Quo]
    * (1 - 'BALANCE Discount %'[BALANCE Discount % Value])

-- The What-If Parameter slider ranges 0% to 60% in 5% increments.
-- Default is set to 40% (0.40), reflecting CMS actuarial estimates
-- of net price reduction under Medicare drug negotiation.
-- Moving the slider live-updates both the projection line and
-- the savings table without any DAX changes needed.

The What-If Parameter setup in Power BI creates a parameter table and a slicer automatically. The measure above references 'BALANCE Discount %'[BALANCE Discount % Value], which returns whatever value the user has selected on the slider. At 0% the two projection lines are identical. At 60% the savings diverge dramatically, which is the point of the visual.

Key Learnings

What This Project Taught Me

This was the first project where I built a model that does not just describe the past but makes a forward-looking claim. Writing the projection DAX forced me to think carefully about what assumptions were baked into the numbers and where those assumptions could be wrong. The What-If Parameter was the most direct way I found to make that uncertainty visible rather than hiding it inside a hardcoded multiplier.

The policy timeline page also changed how I think about time series data. The spending growth is not just a line going up. It tracks almost exactly with FDA approvals and coverage expansions. Putting those annotations on the chart made the data tell a story that the numbers alone never would have.
