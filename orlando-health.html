The Problem

Patient Access Bottlenecks in Referral Workflows

Orlando Health's referral and authorization process contained multiple non-value-added steps that were slowing down patient access to specialty care. Referrals were being entered, tracked, and followed up on inconsistently across clinical teams — leading to delays, lost authorizations, and underutilized capacity.

The goal was to understand exactly where the bottlenecks were, quantify their impact using Epic EHR data, and implement process changes that could be tracked with measurable KPIs.

Before — State of the Process
  • Referral tracking was fragmented across multiple Epic workflows
  • No standardized pre/post authorization measurement in place
  • Non-value-added manual steps delayed specialist access by days
  • No visibility into authorization conversion rates by referral type
  • Clinical staff spending excessive time on manual follow-up
After — Post-Implementation
  • Referral workflow standardized with defined Epic tracking steps
  • KPI dashboard tracking authorization rates week-over-week
  • Non-value-added steps eliminated via DMAIC root cause analysis
  • 200 additional authorizations processed per quarter
  • 60 labor hours per month recovered for direct patient care

Methodology

DMAIC Process Applied

This project followed the Lean Six Sigma DMAIC framework — defining the problem with stakeholders, measuring current-state performance using Epic data, analyzing root causes of referral delays, improving the workflow, and establishing ongoing control metrics.

🎯 Define Stakeholder interviews · Problem scoping
→
📊 Measure Epic EHR data extraction · Baseline KPIs
→
🔍 Analyze Gap analysis · Root cause identification
→
⚙️ Improve Workflow redesign · Process changes
→
📈 Control Post KPI tracking · Validation

Gap Analysis Framework

The core analytical method was a structured pre/post KPI comparison. Baseline metrics were extracted from Epic EHR covering referral volume, authorization conversion rates, processing time, and cost per authorization. Post-implementation metrics were tracked at 30, 60, and 90 days to quantify the impact of each workflow change.

Key Learnings

What This Project Taught Me

This internship reinforced that the most impactful healthcare analytics work isn't just about building dashboards — it's about understanding clinical workflows deeply enough to know which data points actually matter. Asking the right questions of clinical staff (the Define and Measure phases) was more valuable than any query I ran.

It also showed the power of tying analytical findings directly to operational decisions. The gap analysis wasn't just a report — it became the evidence that convinced leadership to approve workflow changes. That's the difference between analysis and impact.
